# ReproduceBlock

Proof that a result can be checked: versions, hashes, seed, and the command that re-runs it.

**Provide**: the replay `header` and the event id.

- Shown on the event page's About tab and in the viewer's info panel; also the data licences (track data ODbL, OSM; TUMFTM LGPL) and the 3D asset licences.
- The command copies with one tap.

Maps to `<ReproduceBlock>`.
