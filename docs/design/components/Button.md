# Button

Actions. `primary` (chalk fill, `on-chalk` text) for the one main action on a screen, `secondary` (outline) for the rest, `ghost` for toolbar actions; `IconButton` for icon-only actions with an `aria-label`.

**Provide**: `variant`, `size` (`m` 36 px, `touch` 44 px), `icon`, `disabled`.

- One primary per view. On phones, primary actions are full width at the bottom of a card.

Maps to `<Button>`, `<IconButton>`.
